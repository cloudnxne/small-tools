# Small tools

| Folder | What it is |
| --- | --- |
| `image-to-webp` | Python command line converter (PNG, JPG, BMP, TIFF, GIF to WebP) with quality, recursion and delete options. Needs Pillow. |
| `platformer` | A small pygame platformer. |
| `home-life` | React and PHP family meal planner that builds shopping lists. Put `homelife.html` and `homelife-data.php` on a PHP host. Start from `homelife-data.sample.json`. |
| `slimming-world-tracker` | Single-file food and weight tracker that stores data in the browser. Unofficial and not affiliated with any diet organisation. |
| `photo-switcher` | Quote email builder that creates Gmail drafts. Add your own Google OAuth client ID in `CLIENT_ID`. All names, images and addresses are placeholders. |
